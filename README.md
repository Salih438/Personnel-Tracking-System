# Personnel Tracking System

A console-based Java application designed to manage employee data, including salary calculations, tax rate enforcement, and performance bonuses. This project was developed to practice Object-Oriented Programming (OOP) principles in a professional, modular structure.

## Features
- **Salary Management:** Sets a minimum salary floor and allows for percentage-based salary increases (raises).
- **Tax Enforcement:** Automatically manages tax rates within a defined range (0% to 40%).
- **Bonus System:** Allows performance-based bonuses to be added to the total gross salary.
- **Net Salary Calculation:** Computes net salary by subtracting tax deductions from gross income.
- **Modular Design:** Clean separation between the `Main` logic and `Employee` class.

## Technologies Used
- **Language:** Java
- **Concepts:** OOP, Encapsulation, Methods, Switch-Case Logic.
- **Tools:** IntelliJ IDEA, Git/GitHub.

## How to Run
1. Ensure you have [Java JDK](https://www.oracle.com/java/technologies/downloads/) installed.
2. Clone this repository: `git clone https://github.com/Salih438/Personnel-Tracking-System.git`
3. Open the project in IntelliJ IDEA.
4. Run the `Main.java` file.
